Carpeta para las imagenes de los productos (deben estar aqui, dentro del proyecto).
Consola: opcion 4 "Agregar imagen a un producto" muestra las imagenes de esta carpeta para elegir una por numero.
Ventana: seleccione un producto > Imagenes > + Agregar imagen, y elija un archivo de esta carpeta.
ejemplo.jpg es una imagen de prueba; se guarda en el producto como: imagenes/ejemplo.jpg
